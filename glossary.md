# Glossary

**Absolute view** — Shows the measured value in its original unit rather than relative to a benchmark (ch09).<br>
**Betweenness centrality** — Measures how often a node lies on shortest paths and may act as a bridge (ch14).<br>
**Business Value Assessment (BVA)** — Weighted assessment of a visualization initiative's business impact (ch12).<br>
**Cascade chart** — Parallelogram-based decomposition of positive and negative contributions to a result (ch07).<br>
**Centrality** — Family of measures used to estimate a node's structural importance (ch14-ch15).<br>
**Circular layout** — Places nodes at equal radial distance to reduce center bias (ch19).<br>
**Community detection** — Assigns nodes to groups based on patterns of shared links (ch15).<br>
**Complexity Score** — Weighted assessment of implementation difficulty across channels, integration, interaction, volume, and related factors (ch12).<br>
**Context backdrop** — Muted benchmark, quartile, target, or distribution layer behind focal data (ch09, ch11).<br>
**Contrail** — Current-value marker with a colored historical trail over a defined range (ch05).<br>
**Data model** — Logical representation of entities, relationships, and properties used for analysis or display (ch16).<br>
**Details on demand** — Interaction that reveals precise attributes only after a user selects or requests them (ch10, ch18).<br>
**Directed acyclic graph (DAG)** — Directed graph without cycles, suited to hierarchy layouts (ch19).<br>
**Diverging bar** — Bar encoding that extends in opposing directions from a shared origin (ch10).<br>
**Eigenvector centrality** — Scores a node highly when it connects to other highly connected nodes (ch15).<br>
**Encoded glyph** — Familiar or abstract symbol whose parts encode multiple properties (ch10, ch17).<br>
**Filter** — Rule that removes currently irrelevant items from a view (ch20).<br>
**Force-directed layout** — Physics-inspired layout balancing attraction and repulsion to reveal network structure (ch15, ch19).<br>
**Gephi** — Desktop graph exploration and visualization tool discussed in the source (ch15).<br>
**Graph** — Model that emphasizes connections among entities (ch13).<br>
**Graph database** — Database that stores nodes and relationships natively (ch16).<br>
**Grouping** — Replaces several nodes or links with a higher-level cluster representation (ch20).<br>
**Hierarchy layout** — Arranges a directed structure in levels from an apex or root (ch19).<br>
**Hyperbolic plane** — Consolidated quadrant system used to rank paired performance measures (ch06).<br>
**KeyLines** — Commercial browser-based graph visualization library used in the source examples (ch15).<br>
**Link/edge** — Relationship connecting two nodes, optionally directed, weighted, typed, or time-stamped (ch13, ch16).<br>
**Marimekko chart** — Rectangular chart whose width and height encode quantities across categories (ch06).<br>
**Mental map** — User's remembered spatial model of a visualization, which unstable animation can disrupt (ch18, ch21).<br>
**Node/vertex** — Entity in a graph (ch13, ch16).<br>
**Node-link diagram** — Common graph view using marks for nodes and lines for relationships (ch13).<br>
**Profile Tile** — Normalized compact view of a security's defining characteristics (ch03).<br>
**Radial layout** — Places focal nodes centrally and organizes other nodes by distance or connection (ch19).<br>
**Relative view** — Expresses a value as an offset, ratio, percentile, or band relative to context (ch09).<br>
**Results Tile** — Compact view of security outcomes, potentially with adjustable weights and drill-down (ch03).<br>
**Shneiderman mantra** — Overview first, zoom and filter, then details on demand; the source extends it with comparison (ch10).<br>
**Small multiples** — Repeated aligned views that compare states or periods (ch21).<br>
**Solution Score** — Combined business-value and complexity decision aid for prioritizing visualization initiatives (ch12).<br>
**Tile Collection** — Grid of consistent Tiles supporting comparison across entities (ch03).<br>
**Time bar** — Interactive time-window control used to filter a dynamic graph (ch21).<br>
**Tooltip** — On-demand attribute panel that reduces surface clutter (ch18).<br>
**Visual encoding** — Mapping from a data property to position, size, color, shape, or another visual property (ch17).<br>
**Visual filtering** — Client-side filtering performed inside the visualization tool (ch20).<br>
**Waterfall chart** — Connected bars explaining how positive and negative components produce a total (ch07).<br>
**Weighted Bubble Cluster** — Non-overlapping bubbles whose size, color, group, and placement encode rank and attributes (ch04).
