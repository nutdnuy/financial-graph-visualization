# Contributing

Thank you for improving this skill. Keep contributions focused on clearer
decisions, more traceable encodings, and reproducible code-native delivery.

## Before opening a pull request

1. Explain the audience, decision, data contract, and expected follow-up questions.
2. Keep examples synthetic or include a clear license and attribution for real data.
3. Keep the editable source with every preview or exported artifact.
4. Do not use Image Generator, `image_gen`, or another generative-image model.
5. Run `python3 scripts/validate_examples.py` and include the result.
6. Check labels, units, baselines, color semantics, accessibility, responsive behavior, and limitations.

Please avoid adding source PDFs or full-page book renders. They are intentionally
outside the public distribution boundary.
